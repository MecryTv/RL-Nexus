# Rang-Karte 1536 × 1024 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die Rang-Karte aus `/rank` und ihre Kopie auf der Startseite der Webseite sind auf beiden Seiten 1536 × 1024 statt 1536 × 1212, mit demselben Inhalt, nach Entwurf A.

**Architecture:** Alle Maße stehen in `Discord Bot/src/constants/RankCard.ts`. Eine neue, reine Funktion `RankCardLayout()` rechnet daraus die Lage der Blöcke (Kopf, Überschrift, Kacheln, Karriere, Stand-Zeile); `RenderRankCard` und die Prüfung lesen sie. Die Webseite (`RankCardPreview`) rechnet weiter in Bot-Pixeln über `b()` und übernimmt dieselben Zahlen.

**Tech Stack:** Bot: TypeScript, `@napi-rs/canvas`, Prüfskript `npm run check:card`. Webseite: React + SCSS (Container-Einheiten `--u`), `npm run lint`, `npm run build`, `npm run check`.

**Spec:** `docs/superpowers/specs/2026-11-17-rang-karte-1536x1024-design.md` (freigegeben 17.11.2026). Mockup A: `.works/tasks/W-0132-rang-karte-wieder-groesser-1436x1024/design/A-alles-bleibt-nur-enger.html`.
