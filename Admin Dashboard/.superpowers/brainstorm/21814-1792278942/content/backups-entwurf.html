Datenbank-Backups: Entwurf

Jeder Server wird jede Nacht um 0:00 gesichert, mit allem: aktive Module, Einstellungen, eigene Nachrichten, Panels und die Daten der Mitglieder (Level, Tickets, Verwarnungen und so weiter). Admins und Developer können zusätzlich von Hand sichern, jedes Backup ansehen und auswählen, was zurückkommt. Oben zwei Möglichkeiten, wo das im Admin Dashboard wohnt; darunter das Ansehen und das Zurückladen, die bei beiden gleich sind. Werte sind Beispiele.
