Wie kommt der Mailclient an die Mails?

Zwei Wege. Klick den an, den du willst. Unten steht, was dafür neu dazukommt.

A

Direkt über IMAP, ohne Kopie Empfehlung

Admin Dashboard⇄ Admin-Server⇄ IMAP / SMTP ⇄ mailcow⇄ SnappyMail, Handy
  • + Gelesen, archiviert, gelöscht wird direkt in mailcow. SnappyMail und Handy sehen genau dasselbe.
  • + Neue Mails meldet mailcow sofort (IMAP IDLE). Sie erscheinen live, ohne Neuladen.
  • + Gespeichert wird nur die Liste der Postfächer mit verschlüsseltem App-Passwort und Signatur. Keine Mails in der Datenbank.
  • + Gesendetes landet automatisch im Ordner „Gesendet“ des Postfachs.
  • − Wie schnell Liste und Suche sind, hängt an mailcow. Dessen Volltextsuche ist aber gut.
B

Alle Mails in die Datenbank kopieren

Admin Dashboard⇄ Admin-Server⇄ MariaDB (Kopie aller Mails)⇄ Abgleich ⇄ mailcow
  • + Liste und Suche sind schneller.
  • − Der Server muss ständig abgleichen, was gelöscht, verschoben oder gelesen wurde. Das ist eine eigene Fehlerquelle.
  • − Jede Mail liegt doppelt vor, auch in jedem Datenbank-Backup. Für den Datenschutz schlechter.
  • − Deutlich mehr Code, länger bis es fertig ist.
